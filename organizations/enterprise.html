The problem

Why this is hard today

Engineering data is sensitive, and teams are spread across sites and suppliers. Cloud-only tools force a trade-off between collaboration and control.

How Ensemble helps

From scattered files to one workspace.

01

Start local

Every user works on their own device, offline, with no account needed. Nothing leaves the machine until someone shares it.

02

Host it yourself

Run the Ensemble server on Windows, Mac or Linux inside your network. It is free.

03

Or let DAFO host it

Use the DAFONET cloud for teams that want zero administration. You can move a workspace from local to a server later.

What you get

Built into the workspace

  • Self-hosted company server, free
  • DAFONET cloud as an option
  • Roles: Owner, Editor, Viewer
  • Local-first: works fully offline
  • Windows, Mac, iPad and Quest VR viewer
  • Plans measured in simultaneous guests, so reviewers can join free
