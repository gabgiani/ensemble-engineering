Use case

Versioning

Every file keeps its history. Every link says which revision it shows.

Get early accessHow it works
The problem

Why this is hard today

“Final_v3_REAL.step” is not a version control system. When the model changes, drawings, notes and quotes quietly point at the wrong thing.

How Ensemble helps

From scattered files to one workspace.

01

Upload a new version

Add a new version of a model or document. The old one is kept and numbered.

02

Choose how each card follows

A card can stay Live, always showing the latest version, or be frozen at a version. A badge shows which mode it is in.

03

Get told when it moves

If a frozen card has a newer version available, you see it, and you can update with one click or keep the frozen one.

What you get

Built into the workspace

  • Numbered versions per file
  • Live or Frozen on every card
  • “Update available” on frozen cards
  • Compare any two versions of a part
  • The same file can appear several times at different revisions
  • Works the same for 3D models, PDFs and office files
